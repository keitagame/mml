Ctrl/Cmd + Enter で再生・停止
MMLリファレンス 
パート: A-F=FM(OPNはA-Cのみ) G-I=SSG J=リズム(OPNA)。行頭にパート名+空白。複数指定可(例: AB)。; 以降はコメント
音符: c d e f g a b  + # 半音上げ - 半音下げ  長さ c4 c8. c%24(clock、全音符=192)  ^ タイ(c4^8)  &スラー(c4&e4)  r 休符
o4 オクターブ  > 上げ  < 下げ  l8 既定長  q1-8 ゲート  _n 移調  v0-15 音量  ( ) 音量-1/+1  t120 テンポ
@n 音色選択(FM)  D n 詳細デチューン(1/64半音)  p1右 p2左 p3中央(OPNA)  L ループ位置  [ ... /... ]n 繰り返し(/は最終回で中断)
SSG: E ar,dr,sr,rr,sl (0-31,sl0-15) ソフトエンベロープ  P1音 P2ノイズ P3両方  w0-31 ノイズ周波数
M delay,speed,depth ビブラート(depth=cent、M0でoff)  H freq,pms,ams OPNAハードLFO(Hのみで停止)
リズム(J): \b ベース \s スネア \c シンバル \h ハイハット \t タム \i リム 例: \bh8 (同時発音可、後ろに長さ)
音色定義: @n alg fb の後に op1〜op4 を各1行  ar dr sr rr sl tl ks ml dt ams  (dtはレジスタ値0-7)
